# Dayline 0.2 · Android

Личный планировщик на Kotlin и Jetpack Compose для Android 8.0+.

## Что умеет

- **Системное оформление.** На Android 12+ палитра берётся из системы (Material You). Есть системная, светлая и тёмная темы. На старых устройствах используется тёплая стандартная палитра.
- **Мой день.** Три свежих события, ближайшие дела и привычки на сегодня.
- **Задачи.** Подзадачи, срок и уведомления за 2 дня, за день и в день срока в выбранное время. Выполненная задача больше не напоминает о себе.
- **Привычки.** Выбранные дни недели, одна отметка в день, история за неделю, серии и медали за 1/7/30/100 выполнений. Отметку можно отменить; выходные по расписанию не разрывают серию.
- **Заметки.** Поиск, два переключаемых представления (карточки / страницы), полноэкранный редактор с автосохранением, заголовками, жирным/курсивным оформлением блока, чек-листами, отступами подпунктов и редактируемыми таблицами. В блочном режиме блоки можно переставлять. Оба режима используют один документ. Это собственный редактор, не встроенный Notion.
- **Будильники.** Дни недели, выбор системной мелодии или своего аудиофайла, вибрация, повтор через 5 минут. После отключения можно открыть утренний обзор.
- **Новости.** RSS и Atom, даты, краткие описания из лент, ссылки на оригиналы, сохранение последнего успешного выпуска. Пресеты: РБК, Лента.ру, Хабр, ТАСС, BBC; можно добавить собственную HTTPS-ленту. Наличие пресета не гарантирует доступность сайта в любой сети.
- **Отбор новостей.** До трёх событий за последние 12 часов, ранжирование по свежести и совпадению заголовков у разных источников; похожие заголовки объединяются. Это приближённый отбор без ИИ, не объективная оценка важности. Статьи без корректной даты доступны во всей ленте, но не попадают в ночной выпуск.
- **Виджет.** Задачи, привычки, ближайший будильник и заголовок из последнего выпуска; переход в приложение и быстрое создание задачи.

ИИ/OpenRouter в эту версию не входит. Ключи не требуются. Личные данные хранятся локально; серверу отправляются только запросы к выбранным RSS-сайтам. Новости требуют интернета. Удаление приложения удаляет локальные данные.

## Установка и обновление

Установите `dayline-v0.2.0-debug.apk` поверх 0.1, **не удаляя старую версию**. Сохранены package ID `app.dayline` и ключ подписи, увеличен versionCode. Старые заметки, задачи, будильники и выбранные источники читаются без сброса. Перед первой записью новой структуры сохраняется локальная копия предыдущих настроек.

Разрешите уведомления и «Будильники и напоминания». На Android 14+ разрешите полноэкранные уведомления в настройках приложения. Ограничения батареи производителя могут задерживать фоновые события. Принудительная остановка в настройках Android блокирует их до следующего открытия приложения. Уведомления о задачах и дайджест используют приблизительное расписание Android; будильник — точное.

Собственный аудиофайл выбирается через системный файловый менеджер с сохранением разрешения чтения. Если файл удалён или доступ потерян, используется системная мелодия. Громкость — системная «Будильник».

Виджет: кнопка в «Мой день» или долгое нажатие на рабочем столе → Виджеты → Dayline. Отображает сохранённые новости, самостоятельно сеть не опрашивает.

## Сборка

JDK 17/21, Android SDK 35 и Build Tools 35.0.0:

```sh
./gradlew --no-daemon --max-workers=2 testDebugUnitTest lintDebug assembleDebug
```

Укажите SDK в игнорируемом `local.properties` (`sdk.dir=...`) либо `ANDROID_HOME`. APK: `app/build/outputs/apk/debug/app-debug.apk`.

В этой облачной среде:

```sh
python /workspace/.android-setup/java-network.py ./gradlew --no-daemon --max-workers=2 testDebugUnitTest lintDebug assembleDebug
```

Используйте существующий checkout. Не создавайте Git worktree без явного запроса пользователя. Установка инструментов описана в сохранённом install_script среды. Снимок файлов и публикация конфигурации не гарантируют переноса процессов и локальных файлов в другие чаты — исходники следует сохранять в Git.

## Проверки

JUnit: перенос состояния 0.1, сохранение таблиц и списков, пустой выбор источников, серии/награды, дни недели и DST будильника, расчёт уведомлений, RSS/Atom с вложенным текстом, безопасные ссылки, временной фильтр и удаление повторов новостей. Android Lint проверяет совместимость с minSdk 26.

На устройстве: установить поверх 0.1, проверить прежние данные, поменять системный акцент и тему, создать заметку с таблицей/чек-листом и переключить оба режима, закрыть и открыть приложение; отметить привычку; проверить будильник через 2 минуты на заблокированном экране, звук, повтор и утренний обзор; обновить выбранные российские источники; добавить виджет. Проверка сетевого доступа из облака не доказывает доступность RSS на телефоне.
